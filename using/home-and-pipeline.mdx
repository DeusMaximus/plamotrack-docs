plamotrack moves every kit through a six-stage pipeline. The Home page is your command centre — it shows what's on the bench, what's waiting, what's in the mail, and what you've finished recently. Everything updates the moment you change a kit's status, so the page always reflects the state of your actual collection.

## The six stages

Every kit you track lives in exactly one of these stages at any given time:

| Stage | Meaning |
|---|---|
| **Pre-ordered** | Ordered but not yet processed or shipped by the shop |
| **Ordered** | Order placed; waiting to ship |
| **In Transit** | Shipped and on its way to you |
| **Backlog** | In hand, not started — yes, we all have one |
| **Building** | Currently on the bench |
| **Complete** | Done — rated, dated, and on the shelf |

"Backlog" means physically in your hands but not yet started. plamotrack is unapologetic about this.

## The Home page

The Home page divides your collection into four sections, each designed to answer a specific question at a glance.

**On the bench** shows every kit currently in Building status. Each card displays the kit's start date, a running day counter, and your most recent build note. If a build is taking longer than expected, you'll know exactly how long.

**Backlog** and **Recently completed** each show the six most recent kits, with the total count displayed beside the heading. Both sections include a "view all" link that opens the full filtered list — so if you have 47 kits in backlog, you're never pretending otherwise.

**In the mail** shows all your outstanding orders — pre-ordered, ordered, and in-transit — as order cards. Each card shows the retailer, carrier, and tracking number (once the order ships). This is the money still in flight.

## Moving a kit

Every card on the Home page has an edit button that opens a dialog where you can change the kit's status. The dialog shows the fields relevant to that particular move:

- Moving to **Building** asks for a build start date.
- Moving to **Complete** asks for a build completion date and a rating.

You can backdate both — log the box when you find the time, not the moment it lands.

## Filtering and browsing

The list pages — Kits, Orders, and others — support filtering, sorting, and pagination entirely through URL parameters. This means you can bookmark any view you use regularly:

- All kits in backlog
- Orders from a specific retailer
- Completed builds in a particular series

Shareable, bookmarkable, and always up to date.

<Tip>
  Complete builds carry a start date, finish date, rating (1–5), and a series name you choose yourself. Series names become filters — "all Iron-Blooded Orphans builds" is a real query. Consistent spelling matters, so check your existing series names before adding a new one.
</Tip>
