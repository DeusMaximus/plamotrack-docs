In plamotrack, an order is a purchase record. When you add an order with two kits in it, plamotrack creates two separate kit rows — because you own two physical objects, not "a quantity of 2". Each kit moves independently through the pipeline, has its own build notes and dates, and can be rated separately when it's done.

## Adding an order

<Steps>
  <Step title="Open Orders and start a new one">
    Go to **Orders** and click **New order**.
  </Step>
  <Step title="Choose a retailer">
    Choose the retailer from the list, or type a new name to create one on the spot. You can fill in the retailer's report card later.
  </Step>
  <Step title="Add order lines">
    Add one line for each type of kit. Enter the kit name, grade, quantity, and unit price for each line. A Zaku ×2 and a GM ×1 are two separate lines.
  </Step>
  <Step title="plamotrack fans out the kits">
    For each line, plamotrack creates that many individual kit rows in your collection. One order line for quantity 2 becomes two independently tracked kits.
  </Step>
  <Step title="Mark it shipped">
    Once the order ships, click **Mark shipped**. All the kits from that order move to **In Transit**, stamped with the ship date.
  </Step>
  <Step title="Mark it received">
    When the box arrives, click **Mark received**. Every kit from the order lands in your **Backlog** at once, and any inventory items on the order count toward your on-hand stock.
  </Step>
</Steps>

## Why individual kit rows?

Each physical kit is its own row, and that has real consequences:

- **Fixing a typo on the order** fixes it on every kit that came from that order — you don't need to edit each kit individually.
- **Deleting an order** cleanly removes all the kits it created. Nothing gets stranded.
- **Shipped kits count down** in the "In the mail" section on the Home page; received kits all land in your backlog together.
- **Stock only changes when the order is received.** A pending order for Tamiya Extra Thin shows it's on order, but the bottle doesn't count as on-hand until the box arrives.

## Adding kits without an order

For gifts, trades, or kits you already owned before you started using plamotrack, you don't need an order record at all.

Go to **Kits → Add kit**. These kits start in whatever status makes sense — typically **Backlog** — without an associated order. All the same fields are available: name, grade, scale, series, build notes, and dates.

## Editing a kit

Every kit has an edit dialog accessible from any list page or card. Open it to update:

- Name, grade, scale, and series
- Status (with the associated dates that go with it)
- Rating (1–5) and build notes
- Build start date and completion date

The dialog only shows the date fields that make sense for the current status. You can update any of these at any time.

<Note>
  Kit statuses for ordered kits are managed through the order. When you mark an order shipped, all its kits move to **In Transit**. When you mark it received, they all move to **Backlog**. From there, move individual kits manually as you start and finish each build.
</Note>
