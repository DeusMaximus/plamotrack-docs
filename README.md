# plamotrack documentation

Source for the plamotrack documentation site, built with [Mintlify](https://mintlify.com). The app itself lives at [DeusMaximus/plamotrack](https://github.com/DeusMaximus/plamotrack).

## Editing

Pages are MDX files; navigation is in `docs.json`. To preview locally:

```bash
npm install -g mint
mint dev
```

`mint broken-links` checks internal links before you open a pull request.

## Screenshots

The images under `images/screenshots/` are generated by the app repository's `frontend/e2e/screenshots.spec.ts` against a throwaway database of invented demo data, one dark and one light capture per view. To refresh them after a UI change, follow the recipe in that file's header comment with `SCREENSHOTS_OUT` pointing at this folder, rather than editing an image by hand.

`AGENTS.md` holds the terminology and style rules for contributors and AI coding agents.
